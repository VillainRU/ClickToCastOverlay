# Click to cast overlay — 1.2.1

Аддон для WoW Retail 12.1.5 (Interface 120105). Без внешних библиотек.

При удержании одного Ctrl, Shift или Alt показывает две иконки назначений выбранного источника: Blizzard или EllesmereUI: слева ЛКМ, справа ПКМ. Считывает профиль Blizzard либо активный профиль EllesmereUI; заклинания вручную в аддоне задавать не нужно. Показывает любые назначенные заклинания, включая лечение и защитные способности. Не применяет заклинания самостоятельно.

## Настройки

`/ctco` — открыть настройки (также Esc → Настройки → Модификации → Click to cast overlay).

- Источник Click Casting: Blizzard (по умолчанию) или EllesmereUI.
- Отдельное окно: снять «Закрепить окно», перетащить область мышью, затем закрепить.
- У курсора: две иконки следуют за мышью.
- На фрейме под курсором: только на союзном фрейме под мышью, включая Blizzard, EllesmereUI UnitFrames и EllesmereUI RaidFrames.
- Размер иконок, промежуток, подписи ЛКМ/ПКМ, смещения X/Y для курсора/фреймов, включение и предпросмотр.
- Положение и настройки сохраняются между входами для аккаунта.

Дополнительные команды:

```
/ctco blizzard
/ctco ellesmere
/ctco window
/ctco cursor
/ctco frames
/ctco unlock
/ctco lock
/ctco test
/ctco refresh
/ctco reset
```

`test` включает/выключает демонстрацию: без модификатора показывает пример двух иконок. С модификатором показывает настоящие назначения. Для проверки фреймового режима навести курсор на фрейм союзника. В режиме перемещения окно также видно без модификатора.

## Поведение

- Если модификаторы отпущены или зажато несколько одновременно — скрыт, кроме предпросмотра/перемещения.
- Нет назначения или назначено взаимодействие «Выбрать цель / Меню» — иконка скрыта без знака вопроса.
- Макрос — сохранённая иконка макроса. Аддон не предсказывает ветви условного макроса и не определяет будущую цель.
- После «Сохранить» в Blizzard Click Casting назначения обновляются в течение секунды. Изменение специализации, заклинаний и макросов также обновляет данные. EllesmereUI перечитывается раз в секунду, а также при смене группы, входе/выходе из боя и смене экипировки.
- Закреплённый оверлей не принимает клики. Незакреплённую область перемещения необходимо закрепить перед игрой.
- Иконки показывают назначение и, по выбору, кулдаун. Они не показывают дальность, доступность или наличие бафа на цели.
- Аддон не меняет защищённые атрибуты и обработчики фреймов. Если WoW скрывает данные фрейма как secret/forbidden, оверлей для него скрывается.

## EllesmereUI

В настройках `/ctco` выбрать источник **EllesmereUI**, либо выполнить `/ctco ellesmere`. Вернуться к Blizzard: `/ctco blizzard`. Выбор сохраняется; обновление не меняет ранее выбранный источник и положение окна.

Для источника EllesmereUI должен быть загружен модуль **EllesmereUI RaidFrames** и включён его собственный Click Casting. Используются его runtime API `CC_GetActiveBindings`, `CC_GetBindingIcon`, `CC_GetBindingUnitType` и `CC_GetClickCastDB` из `EllesmereUI._ModuleNS.EllesmereUIRaidFrames`. Совместимость сверена с установленной версией EllesmereUI 9.5.5. При отсутствии API, выключенном движке или ошибке чтения статус объясняется в настройках; автоматической подмены на Blizzard нет.

Читаются разрешённые EllesmereUI активные назначения текущей специализации и общие назначения после обработки контекста группы, приоритетов и конфликтов самим EllesmereUI. Показаны назначения **кликов по союзным фреймам** во всех трёх режимах размещения. Чистые hover-cast назначения клавиш (без клика по фрейму) исключены. Для назначения «оба режима» учитывается ветка клика. В комбинированных назначениях для союзников и врагов показывается союзная часть. Назначения «только вне боя» скрываются в бою. Выбор цели и меню скрыты.

Макросы, предметы и динамические действия используют иконку, возвращённую EllesmereUI. Она служит обозначением назначения и не гарантирует предсказания условной ветки макроса, воскрешения или другого динамического действия для конкретной цели. Настройки EllesmereUI не изменяются.

## Установка

Папка `ClickToCastOverlay` должна находиться в `_retail_/Interface/AddOns/`, а файл TOC — непосредственно внутри неё. Если аддон добавлен во время запущенной игры и отсутствует в списке, полностью перезапустить клиент. Если он уже загружен, для обновления файлов достаточно `/reload`.

## Проверка в игре

1. Открыть `/ctco`, выбрать «Отдельное окно», настроить положение и закрепить.
2. По очереди удержать Shift, Ctrl, Alt: сравнить обе иконки с сохранёнными назначениями Blizzard. Отпустить клавиши: иконки должны исчезнуть.
3. Проверить «У курсора», затем «На фрейме под курсором» на союзнике и враге.
4. Проверить в группе/рейде на EllesmereUI, включая наведение на иконку дебаффа внутри фрейма.
5. Переключить источник на EllesmereUI; сравнить иконки с его собственными назначениями. Проверить отключение движка, разделение союзник/враг и назначения «только вне боя».
6. В бою проверить отображение и обычный Click Casting. При Lua-ошибке сохранить полный текст из BugSack.

Проверено вне игры: Lua 5.1, синтаксис, загрузка с имитацией WoW UI, модификаторы, пустые назначения, макросы, поиск союзного родительского фрейма, secret/forbidden, команды и настройки. Для EllesmereUI дополнительно проверены переключение источников, отсутствие/отключение/ошибки API, поздняя загрузка модуля, исключение hover-only и враждебных веток, дружественная часть объединённого назначения и ограничения вне боя. Визуальная работа и поведение в настоящем бою требуют проверки в клиенте.

## Новое в 1.2.1

В настройках добавлен переключатель «Показывать кулдаун на иконках» (включён по умолчанию): круговой таймер и числа для заклинаний, восстановления зарядов, предметов и макросов, распознанных WoW. Глобальный кулдаун заклинаний исключён. Умные действия EllesmereUI не получают выдуманный таймер. Пустые назначения скрыты.
